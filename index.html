Tautkan WhatsApp Target Tanpa Scan QR (Pairing Code)
Jika ponsel admin dipegang orang lain dan tidak bisa memindai QR code di layar Anda, masukkan nomor WhatsApp target di bawah ini. Sistem akan meminta kode 8 digit untuk diketikkan langsung di WhatsApp ponsel target.

Kode Penautan WhatsApp Berhasil Diterima
---- ----
Langkah di Ponsel Pemegang WhatsApp:
  1. Buka WhatsApp di ponsel target → Menu titik tiga (atau Pengaturan).
  2. Pilih Perangkat Tertaut → Klik Tautkan Perangkat.
  3. Di bawah jendela pemindai kamera, klik tulisan "Tautkan dengan nomor telepon saja".
  4. Ketikkan kode 8 karakter di atas. WhatsApp akan langsung tertaut ke Kuma!
